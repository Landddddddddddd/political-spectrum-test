# 政治意识形态光谱测试（Political Spectrum / Ideology Test）

一个纯前端、可离线运行的**意识形态自我探索**工具。它不靠「你同不同意」的态度量表打分，而是把你放进具体情景，让你选「你会怎么做 / 怎么想」，再据你选的带特征标签的选项，把你在 8 个维度上定位，并匹配到一个细分的意识形态子类型。

> **边界说明**：本工具是政治哲学的**学术分类**练习，题目与选项均为中性、假设化、日常的情景，不涉及任何具体国家、政府、政党、领导人或现实事件。结果仅用于理解个人价值倾向，**不构成立场判定**。

---

## 一、核心特性

| 特性 | 说明 |
|---|---|
| **8 个维度** | 经济 · 治理 · 文化 · 国际 · 生态 · 技术监控 · 世俗信仰 · 个人集体 |
| **500 题题库** | 30 个领域各约 16–18 题；每题是具体情景，选项数 2–8 不固定 |
| **自适应抽题** | 从题库按你的回答**有目的地**挑题：优先未碰过的领域，并追问你态度还模糊的维度 |
| **题量可选** | 15 / 30 / 50 / 100 题，随选随测 |
| **键盘答题** | 方向键 / WASD 移动高亮，空格 / 回车确认并进入下一题 |
| **1 / 2 / 3 维光谱** | 结果页可切换：单轴滑块、经典政治罗盘（平面）、可拖拽旋转的 3D 立方坐标 |
| **50 种细分结果** | 8 维组合 → 50 个有定义的意识形态子类型（如生态社会主义、民族保守主义、技术自由意志等） |
| **本地优先** | 纯前端、无后端；进度存浏览器 localStorage，可中途退出续测；数据不上传 |
| **可部署** | 构建后是一个静态 `index.html`，可直接托管到任意静态空间 |

## 二、八个维度分别量什么

每个维度有两个相反的极，正交独立：

- **经济 ECO**：平等/再分配（L） ↔ 自由市场/私有/个人责任（R）
- **治理 GOV**：权威/秩序/强国家（A） ↔ 自由/分权/自治（L）
- **文化 CUL**：传统/稳定（T） ↔ 进步/多元/解放（P）
- **国际 NAT**：民族优先/主权/文化边界（N） ↔ 国际协作/世界主义/开放（C）
- **生态 ENV**：增长/发展优先（G） ↔ 生态优先/可持续（S）
- **技术监控 TECH**：集中管控/监控/算法治理（K） ↔ 隐私自主/去中心化/加密（U）
- **世俗信仰 SEC**：世俗公共/政教分离（E） ↔ 信仰入公/信仰社群（F）
- **个人集体 COL**：个人优先/自我负责（I） ↔ 共同体优先/互助/集体责任（M）

结果页里，每一维的位置用连续坐标呈现：

```
位置 = (极1命中数 − 极0命中数) / (两者总命中数)   ∈ [−1, 1]
```

−1 表示完全偏向极0，+1 完全偏向极1，0 表示居中/混合。

## 三、结果怎么算出来

1. **统计**：答完，逐维统计你选的选项把标签投给了哪一极。
2. **定主导极**：票数明显多的一边胜出；平手或都没问到则判为「混合/未定」。8 个主导极拼成你的**维度签名**（如 `R-L-P-C-S-U-E-I`）。
3. **匹配子类型**：拿签名去和 50 个子类型比对——子类型要求的极与你一致 +1、相反 −1、你这维是混合则不计；总分最高者即结果。全混合则回落「温和混合派」。
4. **呈现**：维度签名 + 主子类型名称与描述 + 8 条双极对比条 + 1/2/3 维光谱位置图 + 也较契合的 2 个子类型 + 塑造你结果的关键选择原文。

## 四、目录结构


## 五、本地运行

**方式 A：直接打开**（最简单，但用的还是占位题库，仅看界面）
双击 `ideology-test-adaptive.html` 即可在浏览器打开。

**方式 B：注入真实题库后运行**（推荐）
```bash
node build.js            # 读取 question_bank.json，注入 ideology-test-adaptive.html
                         # 生成 deploy/index.html
# 用浏览器打开 deploy/index.html
```
`build.js` 会把 500 题题库内联进 HTML，生成的 `deploy/index.html` 是**单文件、可离线、可直接托管**的完整成品。

---

## 六、部署

构建产物 `deploy/index.html` 是纯静态页，可直接上传到 GitHub Pages / 任意静态托管：

- **GitHub Pages**：把 `deploy/index.html` 推到仓库，在仓库 Settings → Pages 选对应分支/目录即可。
- **其他静态空间**：CloudStudio、Vercel、Netlify 等均可直接托管。

---

## 七、键盘操作

答题页支持纯键盘：

- `↑ ↓ ← →` 或 `W A S D`：在选项间移动高亮
- `空格` / `回车`：确认当前高亮项并进入下一题（最后一题直接出结果）
